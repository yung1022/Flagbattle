Screen-share live

Uses the YouTube app on your phone. Best if you want zero cloud setup.

  1. Tap Open arena below (fullscreen battle).
  2. Open the YouTube app → create → Go live.
  3. Choose Share screen (or Screen mirroring) and pick this browser.
  4. Start the stream. Keep FLAG BATTLE on screen; don’t lock the phone.
Open arena

Tip: use landscape lock off, brightness high, and plug in power. Shorts / vertical live works best at 9:16.
